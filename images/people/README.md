# People photos

Drop your photos in this folder, then update `people-data.js`.

## Recommended image sizes
- **Profile photo**: 1200 x 900 px (4:3 works best)
- **Group photo**: 1600 x 1200 px (4:3 works best)
- **Member headshots**: 800 x 800 px (square)

The site auto-resizes and crops these consistently:
- Home-page photos use a 4:3 crop.
- Member headshots use a circular 1:1 crop.

## Quick steps
1. Copy image files into `images/people/`.
2. Edit `people-data.js` and replace `src` paths.
3. Optionally set different `photo` values per group member.
